# 全站内容与语言规范

本文约束历史概览、流派、人物、概念卡、地点卡、原书笔记、方法图谱和关系图谱。目标不是让页面字数一致，而是让每一段文字都准确、清楚、自然，并能在全站复用。

## 1. 写作优先级

依次判断：

1. 史实、概念和关系是否准确。
2. 普通中文读者能否一次读懂句子的主语、动作和结论。
3. 术语是否与全站规范名称一致。
4. 在前三项成立后，能否删去重复、铺陈和不增加信息的抽象词。

哲学概念不因追求通俗而失去边界；中文也不因追随英文句法而变得生硬。正文负责解释，希腊语、拉丁语、别名和译名争议优先放入知识卡。

## 2. 自然汉语

- 一个句子优先承担一个主要判断；同时出现定义、背景、比较和评价时应拆句。
- 明确写出谁提出、继承、反对或改造了什么，少用没有施事者的被动句。
- 少用“通过……来……”“将……作为……来理解”“在……的意义上”等可删除的翻译腔。
- 抽象名词连续出现三个以上时，改写为动作关系。例如把“对知识确定性的重建”写成“重新说明知识为何可靠”。
- 不用“提供一种视角”“形成重要影响”“实现某种转向”等空泛结尾；说明视角改变了什么、影响进入何处、转向前后有何差异。
- 段落首句给出中心判断，后续句分别说明理由、机制或限制，不在末句换一种说法重复首句。
- “罗素认为”“现代研究通常认为”“本站将其归入”必须有明确主语，不能混成同一种权威口吻。

## 3. 规范实体

全站只有四个实体真源：

- 人物中文名、英文名、原名和星级：`philosopherProfiles`。
- 流派名称、英文名、类型和星级：`schoolProfiles`。
- 哲学概念、著作和无独立页面人物：`terminology`。
- 地点中文名、英文名、现代位置和历史语境：`geographyEntries`。

正文不得另建一份同义名称表。知识卡由上述数据自动汇总；新增人物、流派或人物概念后，应自动进入行内识别。

当前重点规范：

| 规范名称 | 可在卡片中保留的别名 | 说明 |
| --- | --- | --- |

英文人名以人物资料中的完整常用形式为准；章节标题保留原书目录译法。希腊语、拉丁语和转写不在正文反复并列，统一进入知识卡的“原文／原名”。

## 4. 星级与篇幅

星级表示学习路径中的解释广度和优先次序，不评价哲学价值。应按原书覆盖、问题图谱参与、关系广度、流派角色与跨时代复用独立评定，不得为维持预设人数而升降条目。当前口径与全量结果见 `docs/STAR_RATING_REASSESSMENT.md`。页面篇幅采用近似对数层级，并根据史料状况调整：

| 星级 | 人物页建议正文量 | 流派页建议正文量 | 展开重点 |
| --- | ---: | ---: | --- |
| 1 星 | 约 1,200—1,800 字符 | 约 1,150—1,600 字符 | 为什么需要认识、一个主要问题、关键连接 |
| 2 星 | 约 1,400—2,100 字符 | 约 1,300—1,850 字符 | 两条推导或阶段、主要分歧 |
| 3 星 | 约 1,800—2,600 字符 | 约 1,550—2,200 字符 | 独立体系或问题路线、多个关系节点 |
| 4 星 | 约 2,300—3,200 字符 | 约 1,850—2,600 字符 | 跨时代影响、概念之间的内部结构、主要争议 |
| 5 星 | 约 2,900—4,000 字符 | 约 2,100—3,000 字符 | 全书枢纽、多个问题域、完整传承与批评网络 |

数字是审校提示，不是机械限额。史料稀少的人物不得为凑字数补写推测；低星页面已有高密度可靠材料时也不强行删去。高星页面明显低于建议量时，优先补概念之间的推导、关键比较和现代校正，不补一般性生平。

2026-09-03编辑补充：降低学习成本优先于保全旧卡片。已有知识总量不是需要继续增长的指标；优先保留能支撑核心回答、区分相似观点及帮助记忆的关系。无新增解释价值的旧条目可以删除，不必为它们扩充图谱。共用节点的不同阅读视图只维护一份正文，不能为达到建议字数重复写解释；必要条件、争议和证据边界不可为简短而省略。

全量人物页已经采用核心问题目录、共用图谱和同源阅读面板，不再维护 `inquiries`。新增人物须配置显式选读节点及核心问题；每组至少有本人参与的回答，成员之间须有真实关系，并能返回所属主题。目录顺序不是演绎顺序，共享答案的参与说明必须可见；不能把学派共识、同题比较或本站重构混为人物自己的结论。星级与字数不构成核心问题数量配额。

## 5. 故事、轶事与生活化入口

“故事、轶事与生活化入口”不是每页只能放一条的装饰区。它的任务是从不同方向把读者带回论证：生活场景、公共事件、文本例子、思想实验和真正有解释力的名言可以并列。

- 五星人物至少三条，四星人物至少两条，三星人物至少一条；低星人物不为凑数而加入传说。
- 多条入口必须互补。例如可以分别提供生活场景、可操作的思想实验和文本中的一句话，而不重复同一则名言的不同改写。
- 轶事与流行名言只要证据不足，就在卡片中明确标注来源和限度；传说的文化意义可以保留，但不得伪装成确定履历。
- 每条都应回答“它如何帮助理解此人的问题或方法？”；只因奇特、猎奇或可供背诵而保留的材料应删去。

## 6. 关系标准

人物关系只使用：承接前人、影响后继、同题比较、批评关系、后世重构。流派关系只使用：思想来源、竞争、分化、吸收改造、后世重构。

- “承接前人／影响后继”需要可说明的文本、教学、共同体或明确接受链；相似不等于影响。
- “同题比较”不暗示接触或传承。
- “批评关系”需要明确的反驳、论争对象或有证据的立场冲突。
- “后世重构”必须写清后人如何改变前人的功能，不能只说“产生影响”。
- 关系说明至少包含共同问题和关键差异；目标尽量使用规范实体名，外部人物或传统应在文字中标明为何未进入本站索引。
- 同一直接传承若在双方页面分别写成“承接前人”和“影响后继”，图谱应合并为一条有方向的关系，同时保存双方证据。

## 7. 知识卡

知识卡承担正文不宜反复展开的信息：

- 人物：历史坐标、核心定位、史料边界、核心概念。
- 流派：时期与地区、共同主张、分类边界、代表人物。
- 概念：简明定义、常见译法、使用该概念的人物页面。
- 地点：现代位置、相关历史时期、当时政治语境和地图。

卡片每个字段只回答一个问题。正文已经说清的内容不在卡片中整段复制；卡片也不代替人物或流派详情页。

## 8. 来源与校正

- 罗素的章节负责说明本书如何组织和评价材料。
- 一般史实和概念校正优先使用原始文本、SEP、IEP、大学、博物馆或权威出版社。
- 古代和中世纪生平按“较可靠／传统记载／推定”分层。
- 现代校正应指出具体需要修正的说法，不写成笼统的“现代研究更复杂”。
- 引文无法核实原文时改为转述；流行名言不得冒充逐字原话。

## 9. 审校顺序

每次新增或改写内容依次检查：规范名称 → 关系方向 → 概念定义 → 中文语序 → 重复信息 → 来源语气 → 行内识别 → 星级篇幅。完成后运行 `npm run audit:content`、构建、测试和离线构建。
