# 全站术语识别与弹窗覆盖审计

> 完成日期：2026-09-04
> 范围：人物、流派、历史、原书章节、问题图谱原子节点与 5／10／20 总结节点的用户可见数据文本

## 结论

全站现统一使用“正文表层词 → 规范术语卡 → 通用说明 → 人物语境义项”四层结构。人物 `CONCEPT SYSTEM` 中的 367 条已审定定义全部进入语境义项，不再把同名词的多个人物定义拼成一段文字。

问题图谱的节点标题、摘要、逻辑压力、后续问题、解释边界、问题家族与总结卡详情现均通过同一行内识别器。人物、流派和历史页里的局部图谱同样传入这个渲染器，不再维护另一套交互。SVG 图形内的文字仍保持为选择节点的单一操作；选中后在旁边的 HTML 详情区点击术语，避免在一个图谱按钮中嵌套另一个按钮。

## 可重复的盘点

`npm run audit:terminology` 直接扫描各主数据模块，当前结果为：

- 31,378 个用户可见数据字符串，合计 732,164 个字符。
- 641 张知识卡：89 人物、47 流派、379 概念、122 地名、4 著作。
- 679 个可行内识别的规范名或别名；其中 667 个实际出现在当前语料，可到达 636 张卡片。未出现的卡片作为别名或后续扩展入口保留，不代表断链。
- 367 个人物语境义项与 82 位人物当前定义逐条同步。
- 每个可识别表层都必须解析到非空弹窗说明；当前审计为 0 错误。

## 本轮补入的跨人物术语

语料扫描确认了 7 个高频、高信息量、但不应强行归属某一人物的入口：

- 目的论：目的或功能解释；不必预设外在设计者。
- 机械论：区分十七世纪机械哲学与当代机制解释。
- 决定论：由状态和自然律固定后续；不等于可预测性或宿命论。
- 观念论／唯心主义：作为多种立场的家族名，不压缩成“否认外界”。
- 唯物主义：区分古代原子论、近代唯物论与历史唯物主义。
- 必然联系：作为因果争论的专门入口，保留休谟对“恒常结合”与必然性的区分。
- 生产关系：不与“生产方式”混同，而是说明前者如何进入后者。

审定依据主要使用 SEP 的 Aristotle、Mechanisms in Science、Causal Determinism、Idealism、Physicalism、Hume 和 Analytical Marxism 条目，网址已纳入 `concept-review-ledger.json` 的通用定义记录。

## 别名与误标控制

安全别名现可直接解析到同一卡片，例如“始基 → 本原”、“理型 → 理念”、“自在之物 → 现象与物自身”、“定言令式 → 绝对命令”、“先定和谐 → 预定和谐”与“摹状词 → 摹状词理论”。“心灵宁静”虽也可作 *ataraxia* 的译法，但本站已有伊壁鸠鲁的同名人物义项，因此不把它强制别名化为“不动心”。正文始终保留作者原来使用的表层词，只在弹窗中显示规范卡名，避免别名识别反向改写句子。

“道”、“形式”以及人物栏中的“水、气、爱、争”都不进入全站行内识别：它们过短或歧义过高，自动高亮会显著提高噪音。四个单字人物概念在各自 `CONCEPT SYSTEM` 标题上仍可直接点击弹出说明，因此没有丢失定义，只是不在普通句子里到处标记。

## 后续维护约束

1. 新增人物概念时，必须同时出现在人物语境义项中。
2. 新增全站别名时，必须显式指定规范词；不把“其他译法”机械全部加入行内识别。
3. 新增跨人物概念时，先判断是否真有可稳定定义的术语边界，再补通用卡和来源；不高亮“知识、真理、存在、正义”等在全站频率极高、且无上下文时不能唯一定义的普通哲学词。
4. 提交前同时运行 `npm run audit:terminology`、`npm run audit:content` 和自动测试。
