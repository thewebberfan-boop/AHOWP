# 项目状态

更新日期：2026-08-20
当前分支：`main`

## 当前目标

以罗素《西方哲学史》为主轴，建立适合历史型学习者的交互知识结构。内容不是原书复述，而是通过历史阶段、共同问题、流派回应、人物版本和原文章节逐层下钻。

## 已确认的设计共识

- 历史和历史阶段是最高层、最低成本的知识架子。
- 优先保留简单、重复出现、能连接更多知识的关系。
- 流派是共享前提、方法、概念或生活方案的传承关系，不是时代问题的来源。
- 哲学家页面是第一次深入具体观点和推导的层级，但仍须结构化，不能变成连续小传。
- 信息密度和信息质量优先于机械字数；人物篇幅随重要性和证据量变化。
- 中文解释为主，人名、地名、概念保留中英双语。

## 已知缺口

- 原书索引只有少数章节拥有完整结构化笔记，大量章节仍只有目录元数据。
- 哲学家页面目前只有第一批 5 人，尚未扩展到全书。
- 搜索已经能命中第一批哲学家，但尚未建立完整人物交叉索引。
- 人物关系仍主要在各人物页面中表达，尚无全局人物关系图。
- 部分人物图像仍是占位或后世想象图，需要后续按统一流程补充。
- 地点已有全局识别，但古地图资料仍不完整。
- 当前主要是单页状态切换，不是可独立分享 URL 的多路由详情页。
- 离线版的在线地图和外部资料链接在断网时不可用；若需要完全离线地图，需另建地图资源包。

## 建议的下一步

用户目前正在以小批次方式验证“哲学家”页面。下一步应先收集对首批页面的信息密度、栏目和比较方式的反馈，再决定：

1. 继续补下一批哲学家；或
2. 先优化哲学家页面结构；或
3. 回到原书索引，补齐对应章节的结构化笔记。

不要在没有用户确认的情况下立即批量生成全书哲学家资料。
