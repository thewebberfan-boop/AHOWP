# 项目状态

更新日期：2026-08-27
当前分支：`main`

## 当前目标

以罗素《西方哲学史》为主轴，建立适合历史型学习者的交互知识结构。内容不是原书复述，而是通过历史阶段、共同问题、流派回应、人物版本和原文章节逐层下钻。

## 已确认的设计共识

- 历史和历史阶段是最高层、最低成本的知识架子。
- 优先保留简单、重复出现、能连接更多知识的关系。
- 流派是共享前提、方法、概念或生活方案的传承关系，不是时代问题的来源。
- 哲学家页面是第一次深入具体观点和推导的层级，但仍须结构化，不能变成连续小传。
- 信息密度和信息质量优先于机械字数；人物篇幅随重要性和证据量变化。
- 中文解释为主，人名、地名、概念保留中英双语。
- “问题图谱”的节点是问题与思想动作，哲学家只是提出、回答、反驳或重构这些节点的参与者；逻辑连接必须与历史影响分开标注。

### 主视图与导航

- 启动时先显示独立首页，提供“开始历史之旅”和“继续上次学习”两个入口。“开始”固定打开第一个历史时期及其第一项时代回应；“继续”通过当前浏览器的 `localStorage` 恢复上次页面、选中对象、纵向位置和历史／流派／人物／章节返回链。首页本身不覆盖学习进度；学习界面左上角标题可保存当前位置并返回首页。进度属于当前浏览器，不在设备间同步。
- 点击顶部“哲学家”或“哲学流派”时分别进入对应关系图谱，左侧具体人物／流派卡再进入详情页。
- 顶端导航为“历史概览 → 哲学流派 → 哲学家 → 问题图谱 → 原书索引 → 方法图谱 → 关系复习”。
- 每个阶段包含历史事件、时代问题、哲学流派、哲学家和原书章节。
- 已建立独立“哲学流派”视图，以 32 个高密度页面连接历史阶段、共同问题、人物与原书章节。
- “历史概览”已经成为 11 阶段主入口；正文内重复的横向阶段索引已删除，只使用左侧阶段索引。
- 独立“原书结构”视图已经取消。原有 9 个基于罗素目录的重构框架保留为数据层，并显式映射到历史概览各阶段的“罗素原书中的位置”区块；该区块只显示原书范围、组织线索和分组章节，避免再次复制事件、问题、流派和人物页面。
- 历史概览的每种“同期回应”现可继续下钻到相关流派与关键哲学家。连接使用独立 ID 数据保存，不靠页面文案猜测；进入详情时会记录历史阶段、当前回应和精确滚动位置，返回后恢复原处。历史 → 流派 → 哲学家形成两级返回链，先回流派原位置，再回历史原位置。
- 进入历史概览、哲学流派或哲学家视图，或在各自左侧索引中切换当前对象时，左侧滚动区会无动画地将对应阶段卡、流派卡、人物卡（图谱状态则为图谱入口）定位到可视区域中间；右侧主阅读区的原位恢复不受影响。
- 正文内已建独立页的哲学家与流派名称不再打开术语弹窗，而以深绿虚线和 `↗` 标识进入对应详情页；概念、地点、尚未建立独立页的人物等仍使用原有弹窗。此类正文下钻会保存完整页面状态和精确滚动位置，并支持人物／流派之间的连续返回链。各主页面的大标题只作静态身份展示，不参与正文实体下钻或术语弹窗。
- 手机竖屏（760px 及以下）中，历史概览、哲学流派、哲学家和问题图谱四个主要页面不再把完整左侧索引置于正文之前，而是在顶部导航下改用横向滑动轨道。轨道卡片按实际信息宽度自然收缩，只为过长内容设置上限；当前卡居中、相邻卡露边并使用滚动吸附。用户松手后自动切换最近的阶段、流派、人物、图谱入口或问题阶段，切换时仍保持正文的对应阅读位置。桌面与平板继续使用完整左侧索引；手机全站搜索改为顶部的紧凑入口。
- “方法图谱”“原书索引”“关系复习”已经存在。
- 原书章节能够返回此前的历史、流派、哲学家、问题图谱、方法或复习位置。

### 问题图谱：第一条试验谱系

- 顶部“哲学家”之后已增加独立“问题图谱”页面。它不使用自由漂浮的力导向图，而以稳定的方向性阅读结构显示“为什么下一步会出现”。
- 当前第一条谱系为“从差异与变化到可知的形式”，覆盖泰勒斯至柏拉图，并以“观察差异 → 同一产生多样 → 埃利亚逻辑压力 → 多元论保存变化 → 感觉与知识”五个阶段组织 19 个思想节点。
- 节点类型包括观察、问题、区分、回答、反驳、修复、转向和开放问题；连线分别标记原书线索、历史回应、同题并列、本站推演和后世重构，防止把逻辑上的连续阅读误写成直接师承。
- 人物以“在这里思考的人”附着在节点上，可进入现有哲学家页并沿特制返回链恢复图谱精确阅读位置；节点也可进入相关原书章节并返回。埃利亚的芝诺因尚无人物详情页，明确显示“人物页待补”。
- 桌面左侧索引和正文置顶阶段导航同步当前阅读阶段；手机使用与其他主要页面一致的横向滑动轨道。全站搜索已可命中问题、思想动作、参与人物和逻辑关系。
- 已新增 `docs/PROBLEM_MAP_GUIDE.md` 作为独立接手手册，记录首条谱系的稳定 ID、内容语法、五种连接证据、参与人物和章节引用规则、页面状态与返回链、搜索行为、续写亚里士多德的入口、多谱系前置改造、验证命令和跨电脑恢复步骤。

第三卷沿用同一标准：专章人物全部进入；伊拉斯谟、莫尔、路德、哥白尼、开普勒、伽利略、边沁、密尔、弗雷格和罗素虽分布在主题章中，但承担了可独立展开的方法、制度或思想转折，因此保留人物页。科学家和拜伦页明确说明其进入哲学史的功能边界，不把他们伪装成具有完整哲学体系的同类人物。第三卷历史概览的全部回应现已同时连接相关人物和现代流派页，形成“历史阶段 → 回应 → 流派 → 人物”的连续下钻。

每页包含证据分层生平、时间线、问题与推导、核心概念、流派关系、影响与同题比较、罗素观点、现代校正、来源和原书跳转。人物关系现使用“影响后继、承接前人、同题比较、批评关系、后世重构”五类；前两类以当前人物为观察点，分别表示向后影响与向前承接，为后续人物关系图保留明确方向。第二批围绕“巴门尼德的逻辑约束 → 多元论保存变化 → 原子论以原子和虚空重构变化”形成连续问题链；第三批继续覆盖“智者与苏格拉底的问题转向 → 柏拉图与亚里士多德的系统建构 → 犬儒、怀疑派与伊壁鸠鲁派的生活技术”；第四批完成“斯多葛主义的创立 → 系统化 → 罗马化 → 角色实践”，再以普罗提诺收束第一卷。证据稀少人物按资料可靠度主动缩短，并明确区分同期材料、后世传记与现代推断。

哲学家左侧索引已增加“哲学家图谱”入口，顶部“哲学家”也默认进入该图谱；图谱从现有人物页关系数据自动去重汇总 82 位人物和 203 条关系边。人物页仍保留“承接前人／影响后继”两个观察方向，图谱则把它们合并为同一条“前人 → 后人”箭头，聚焦不同端点时显示相应标签和该页证据，避免双方各录一次后画成重线。比较、批评与后世重构继续保持独立语义。人物节点按与流派图谱相同的九个历史—方法群聚类，副标签直接采用流派页的规范分类，而不依赖人物资料中的自由文本。图谱支持节点拖拽、画布平移、滚轮／双指缩放、按钮缩放、复位、显示全部关系和键盘节点聚焦；D3 视区为 1000×440，以减少桌面端纵向滚动。
