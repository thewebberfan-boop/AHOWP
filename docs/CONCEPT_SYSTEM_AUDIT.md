> 审定基线：`472efe6`
> 范围：82 位哲学家页面的 367 条定义，以及不属于任何单一人物的全局通用概念

## 结论

本轮已经逐条读完并登记 367 条人物页定义。上一轮所说的“18 位哲学家、21 条定义有问题”不是完整结论，只是第一批高置信发现；不能据此推断其余 346 条已通过复核。

完整复核后的处理结果是：

| 处理 | 数量 | 含义 |
| --- | ---: | --- |
| 修订 | 70 | 纠正概念关系、补足关键条件、收窄人物归属，或标明后世／本站重构 |
| 保留 | 297 | 当前定义可用；其中有些仍须带着文本、时代或解释争议来读 |
| 合计 | 367 | 与当前 82 位人物页逐条对应 |

证据状态不是“正确／错误”的二分：

| 证据状态 | 数量 | 含义 |
| --- | ---: | --- |
| supported | 180 | 权威资料可直接支持当前核心表述 |
| qualified | 186 | 表述可用，但人物归属、文本证据或学术解释需要限定 |
| limited | 1 | 证据很弱，只能作为接受史线索保留 |

因此，70 条“修订”不等于发现 70 个同等严重的事实错误。多数修改处理的是一种更隐蔽、也更影响学习的风险：把后世术语写成本人原话，把争议解释写成定论，或把本站的学习性概括写成历史人物自用概念。

## 复核标准

每条定义都至少经过以下五项检查：

1. **定义对象**：文字是否真正说明“它是什么”，而不只是说“它很重要”。
2. **人物归属**：是本人可支持的观点、后世学派的系统化、他人转述，还是本站重构。
3. **必要条件**：有没有遗漏会改变含义的条件，例如詹姆斯的“切实、不可回避、重大”选项。
4. **解释边界**：是否把有争议的解释写成唯一答案，或套用现代概念制造时代错置。
5. **术语类型**：它究竟是概念、论证、方法、著作、传统标签，还是本站编辑性标签。

当前 367 项按知识性质分为：

| 类型 | 数量 |
| --- | ---: |
| 概念 | 300 |
| 方法 | 19 |
| 论证／主张 | 16 |
| 后世传统 | 13 |
| 本站编辑性标签 | 10 |
| 著作／文本装置 | 9 |

这些项目仍可共同出现在“CONCEPT SYSTEM”，因为它们都能降低理解人物思想的成本；但下一阶段的弹窗应显示类型，不能把六类内容伪装成同一种“定义”。

## 代表性修正

- **苏格拉底的助产术**：原文“柏拉图以其母亲职业作比喻”会误指母亲。现改为《泰阿泰德》中的苏格拉底以自己的母亲为接生婆作比喻，并标出对话人物与历史本人不能直接等同。
- **皮浪与后期皮浪主义**：悬置、等力、依表象生活等系统术语主要由数百年后的传统保存和定型；人物页现在逐项显示这层归属。
- **克律西波斯的可说之物**：不是一切 lekton 都可真或假；只有断言具有真值，疑问和命令等也属于完整的可说之物。
- **阿维森纳的意向**：改正了羊与狼的方向。羊把握的是狼所呈现的危险或敌意，不是“羊对狼的敌意”。
- **安萨里的《哲学家的不一致》**：二十个问题不是全部属于形而上学，而是十六项形而上学、四项自然学。
- **波那文图拉的心灵旅程**：终点是超越有限受造层次而趋向上帝，不是“超越上帝”。
- **莱布尼茨的可能世界**：同一世界内的个体须共可能；不同可能世界之间恰可包含彼此不相容的选择。
- **贝克莱的非物质主义**：不只是说物质实体“解释上不必要”，而是否认独立物质基底；他仍承认苹果、树木等普通对象。
- **斯宾诺莎的充分观念**：补回《伦理学》II 定义 4 的“内在性质”和充分原因，不再以“共同原因”作不准确替代。
- **詹姆斯的信念意志**：补回切实、不可回避、重大且证据不能预先裁决的条件，避免变成“相信任何有用主张”。
- **弗雷格的意义与指称**：补充“有意义但无指称”的表达式，以及间接语境的变化，避免暗示每个有意义表达式都必有对象。
- **密尔的伤害原则**：保留核心原则，同时揭示原文的文明等级限制，避免把经过现代化的版本无条件归回密尔。

## 关于“全站定义都应出现在某位哲学家的定义栏目”

严格说，这个假设不成立。

人物页共有 367 条定义，但只有 357 个不同中文条目；同名条目可能在不同人物那里承担不同含义。人物定义审定完成时，全局词库有 16 个没有以同名条目出现在任何人物概念栏中的通用概念：

> 德性、恩典、救赎、共相、信仰、理性、启示、经验、归纳、因果、社会契约、主权、自然权利、自由、近代科学、现代可错论

随后的全站语料扫描又确认必然联系、目的论、机械论、决定论、观念论、唯物主义和生产关系 7 个跨人物入口，因此当前为 23 个。详见 [全站术语识别与弹窗覆盖审计](TERMINOLOGY_POPUP_AUDIT.md)。

不应为了获得弹窗覆盖，把它们强行塞进某一人物页。例如：

- “因果”有亚里士多德、休谟、康德等不同理论，通用入口不应归某一个人所有。
- “自由”横跨意志自由、政治自由和斯多葛式内在自由。
- “近代科学”是跨人物、跨方法的历史类别，不是某位人物的私人概念。
- “恩典”和“救赎”属于跨作者的神学语汇，不宜由奥古斯丁或路德独占。

因此，后续弹窗已采用两层结构：

```text
全局通用术语
└── 人物／文本语境中的具体义项
```

正文识别“因果”时先打开通用说明，再列出休谟、康德等人物义项；在人物页点击“充分观念”时则直接打开斯宾诺莎义项。这样既统一交互，也不会牺牲哲学差异。

## 已为全站识别阶段完成的准备

1. 367 条人物定义已经有稳定的“人物 ID + 中文术语”身份和文本哈希。
2. 每条都有审定结论、证据状态、知识类型和至少一个来源链接。
3. 全局通用概念与人物语境义项已经分开，不再假设所有词必须归某个人。
4. “谱系／谱系学”“因果／因果性”等别名已归一。
5. 人物概念卡片点击后的弹窗，现强制使用当前人物定义；不会再出现卡片正文已更新、弹窗仍显示另一人物或旧全局解释的情况。
6. 自动测试会在定义新增、删除或改写后提示审定台账过期，避免“页面变了，审核状态仍显示完成”。
