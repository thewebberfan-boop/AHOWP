# 视觉知识储备

这个目录暂不决定网页中的最终呈现方式，只保存未来可以复用、检索和核对的视觉知识。

## 地理资料

权威数据位于 `app/geography-data.ts`。每个地点保存：

- 中文名与英文名；
- 现代地理位置和坐标；
- 地名在本书所述时期的名称、政治环境与地图范围；
- 现代 OpenStreetMap 入口；
- 古代 Pleiades 地名志检索入口。

“古地图”在这里指按思想发生时期重建的历史语境地图，不把古人绘制、比例失真的地图与现代定位图混为一谈。未来界面应允许在“时期地图”和“现代地图”之间切换，同时保持同一个地点被选中。

## 人物图像

人物清单和图像元数据位于 `figures.json`，本地图片位于 `public/visual-archive/figures/`。每条记录保存：

- 人物的中英文名称；
- Wikidata、Wikipedia 与 Wikimedia Commons 来源；
- 本地图片路径；
- 作者／馆藏署名、许可名称与许可链接；
- “是否需要人工复核”的状态。

古代和中世纪人物往往没有写实肖像。雕像、钱币、手稿插图和后世画像只能作为视觉识别符号，不能暗示它就是人物真实面貌。没有可靠图像时，资料库会明确保留缺口，不用生成式假头像补齐。

## 使用原则

1. 中文知识结构不依赖图像才能被理解；图像用于识别、记忆和定位。
2. 所有外部图像在进入网页前必须保留来源和许可。
3. 地图必须同时提供历史语境与现代坐标，两种视图共享同一地点记录。
4. 人物卡片应注明图像类型，例如“古代胸像”“后世版画”“同时代照片”。
5. 当前资料库是底层资产，不代表最终网页布局。
